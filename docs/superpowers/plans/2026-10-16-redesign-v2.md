# Redesign Stefe.app v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform stefe.app from a dark/geek aesthetic to a luminous, modern, teal-accented portfolio with conversational tone and subtle 80s touches.

**Architecture:** In-place restyling of existing React SPA. No new pages or routes. Changes flow bottom-up: Tailwind config & CSS foundation first, then data/content rewrite, then each component adapted. A new `useTheme` hook manages dark/light toggle.

**Tech Stack:** React 19.3, TypeScript 6, Tailwind CSS 3.4, Vite 8.3, lucide-react

**Spec:** `docs/superpowers/specs/2026-10-16-redesign-v2-design.md`

## Global Constraints

- Stack unchanged: React 19 + TypeScript + Tailwind 3.4 + Vite
- All content lives in `src/data/content.ts` (data-driven)
- French only
- Project grid: uniform 1x1 tiles, never enlarge a tile
- No new pages, no new dependencies except potentially a Google Font
- `darkMode: 'class'` already configured in Tailwind

## Review Focus

1. **System `prefers-color-scheme` mismatch:** User with dark OS preference visits for first time — should respect system preference, not force light. Verify `useTheme` reads `prefers-color-scheme` before localStorage.
2. **Tailwind dark: class propagation:** Every component hardcodes light classes — verify all text/bg/border classes have `dark:` counterparts or use CSS custom properties.
3. **Sunset gradient accessibility:** Peach/coral accent on white background may have low contrast — verify decorative elements don't carry meaning-bearing text.
4. **Mobile filter tabs overflow:** Category tabs in ExpertiseStack may overflow on small screens with new styling — verify horizontal scroll still works.
5. **Form input readability in light mode:** Current inputs use dark bg — verify light mode inputs have proper contrast and visible borders.

**Interfaces:**
- Consumes: nothing
- Produces: `useTheme(): { theme: 'light' | 'dark', toggle: () => void }` — reads `localStorage.getItem('theme')`, falls back to `window.matchMedia('(prefers-color-scheme: dark)')`, toggles `dark` class on `document.documentElement`, persists to localStorage.

- [ ] **Step 1: Create `src/hooks/useTheme.ts`**

Export `useTheme` hook. On mount: check `localStorage.getItem('theme')`; if null, check `window.matchMedia('(prefers-color-scheme: dark)').matches`; set `document.documentElement.classList` accordingly. `toggle()` flips the class and persists. Return `{ theme, toggle }`.
